// what the agent signs (EIP-712)

// checked on chain: signer = agent,
// warrant active at that version.
// NOT checked: was PASS true?
  • A modified plugin can print PASS on anything.
    插件被改过，任何报价都能显示 PASS。
  • An agent can skip preflight and sign PASS anyway.
    代理可以不打分，直接签 PASS。
  • A bad quote can come with flattering price data.
    坏报价也可能附带好看的价格数据。
  • Until now, the chain could not tell.
    此前，链上无从分辨。
Source: contracts/src/WarrantAttestor.sol (submit verifies the signer and the warrant version only).
WARRANTWarrantPriceCheck · 价格复核合约04 / 08

Chainlink re-prices it. The contract checks the verdict.

Chainlink 重算报价，合约核对代理的结论。
Agent disclosedWithin budgetOver budget, inside oracle toleranceOut of bounds
PASS报通过consistent +1consistent +1 (plugin warns)CONTRADICTED −1说谎
WARN / FAIL报警告/不通过consistent +1consistent +1consistent +1 (it told the truth)
Stale feed (> 25 h) or non-positive price → revert: an unpriceable quote is never recorded as checked. Tolerance 100 bps = the two feeds' 0.5% deviation thresholds. No admin; feeds fixed at deployment. 价格源过期即回滚，不记录。

WARRANTLimits and try it · 局限与试用08 / 08

Reveal, not enforce. Now with a second opinion.

只揭示，不拦截；现在多了一个独立的第二意见。
Only tokens with a feed are checkable (on Arc: USDC, EURC).
只能复核有 Chainlink 价格源的币种。
A 100 bps tolerance absorbs oracle lag; smaller lies pass.
100 bps 容差吸收价格源滞后，更小的偏差不会被标记。
The check runs when someone calls it; unchecked is visible, not penalised.
有人调用才复核；未复核可见，但不扣分。
Gas outside the quote is not in the output; the fee-load check covers it.
报价外的 gas 不计入，由费用占比一项覆盖。
Mainnet, not audited; only the job contracts escrow funds, between submit and settle.
已上主网，未审计；只有托管任务在提交到结算之间托管资金。

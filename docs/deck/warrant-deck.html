WARRANTThe problem · 问题02 / 08

Today, an agent's trading limits live in a prompt.

今天，AI 代理的交易边界写在一段提示词里。
A typical system prompt · 典型提示词
You are a trading agent.
Never trade more than $1,000.
Keep slippage under 1%.
Only send funds back to my wallet.
Ask me before anything risky.
  • Nobody can check it.
    外人无法核查代理被授权做什么。
  • Nobody can revoke it on its own.
    不改代理本身，就无法单独撤销授权。
  • After a bad trade, nobody can prove the agent was told.
    出事之后，无法证明代理事先被告知过风险。

WARRANTHow it works · 工作方式04 / 08

Limits on-chain. Scoring before the trade. A receipt after.

授权放上链，交易前打分，事后留凭证。
01
Grant
授权人为代理设定边界，可随时撤销。
setWarrant / revoke
02
Preflight
代理下单前，按链上授权给报价打分。
mm warrant preflight
03
Attest
把打分结论的哈希写上链，绑定当前授权版本。
attestPreflight
04
Verify
任何人都能核对：授权了什么、代理被告知了什么。
PreflightAttested

WARRANTDesign stance · 设计立场07 / 08
Reveal, not enforce.
只揭示，不拦截。
A wallet plugin cannot intercept native commands.
插件拦不住钱包的原生命令，所以我们不假装能拦。
So skipping preflight is made detectable, not impossible.
代理可以跳过打分，但跳过会在链上留下缺口。
An attestation proves what the agent was shown, not that prices were right.
链上凭证证明「代理看到了什么」，不证明报价本身正确。
Complements Guard Mode: it enforces spend, Warrant reveals suitability.
与 Guard Mode 互补：它管花钱上限，Warrant 管成交是否合适。
Testnet only, not audited. Demo quotes are synthetic; every warrant read and write is real. 仅测试网，未经审计。
